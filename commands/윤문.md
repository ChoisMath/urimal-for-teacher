# /윤문

`urimal-for-socialworker` 스킬을 트리거합니다. 사회복지사가 쓴 계획서·주간업무보고서·사업보고서를 우리말 36항목 + AI 티 탐지 두 레이어로 정밀 분석한 뒤, 6에이전트 파이프라인으로 윤문해 줍니다.

## 사용

```
/윤문 [입력]
/윤문 docs/2026_사업계획서.hwpx
/윤문 docs/주간업무보고서.hwp 정밀 모드
/윤문 (붙여넣은 텍스트) 장르: 보고서, 강도: 보수적
```

## 입력 처리 규칙

`urimal-for-socialworker` 스킬을 호출하여 입력을 처리한다. 다음 단계를 따른다.

1. **입력 정규화**
   - 인자가 파일 경로(`.hwp`, `.hwpx`, `.pdf`, `.docx`, `.xlsx`)이면 → `kordoc` 스킬을 먼저 호출하여 마크다운으로 변환한 뒤 그 결과를 윤문 대상으로 사용
   - 인자가 `.txt`, `.md`이면 → 직접 Read
   - 인자가 텍스트(붙여넣기)이면 → 그대로 입력

2. **옵션 파싱** — 자연어 옵션을 다음 키로 매핑
   - "정밀 모드", "opus", "최고 품질" → `model: "opus"` (`claude-opus-4-7`)
   - 기본값 → `model: "sonnet"` (`claude-sonnet-4-6`)
   - "강도: 보수적", "원문 톤 살려줘" → `over_polish_threshold: 0.20` (변경률 상한 낮춤)
   - "장르: 계획서|보고서|안내문|공적연설" → `genre_hint`로 전달
   - "최소심각도: S1|S2|S3" → `min_severity`

3. **스킬 호출** — `urimal-for-socialworker` 스킬의 오케스트레이터(`scripts/orchestrator.md`)를 트리거하고 Phase 0부터 진행

4. **출력** — `_workspace/{run_id}/final.md` + `summary.md`를 사용자에게 반환

## 동작 정책

- **수치·고유명사·인용은 절대 변경 금지** (Do-NOT list 엄수)
- **변경률 30% 초과 시 경고, 50% 초과 시 강제 중단**
- 결과 등급 B 이하면 "2차 윤문을 원하시면 말씀해주세요" 자동 안내
