# 학생 성적 확인 웹앱 (Google Apps Script)

학생이 **학번 + 이름**으로 로그인하면 다음을 보여 주는 웹앱입니다.

1. 문항별 점수와 총점 — 한 행짜리 표
2. 전체 평균, 표준편차, 응시 인원
3. 총점 히스토그램 — 본인이 속한 구간만 주황색으로 강조, 평균은 파란 점선
4. 등급 가능성 안내 — 나머지 평가가 모두 100점일 때 도달 가능한 최고 등급
   - 67점 이상 → A등급 가능
   - 34점 이상 → B등급 가능
   - 0점 이상 → C등급 가능
5. 본인 답안지 PDF — iframe으로 표시

다른 학생의 개별 점수는 브라우저로 보내지 않습니다. 평균·표준편차·구간별 인원만 전달합니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `Code.gs` | 서버 코드: 시트 읽기, 로그인 확인, 통계, PDF 찾기, 교사용 메뉴 |
| `Index.html` | 페이지 구조 (로그인 화면, 결과 화면) |
| `Stylesheet.html` | 스타일 |
| `JavaScript.html` | 화면 그리기: 표, 히스토그램(SVG), 등급 안내, PDF iframe |
| `appsscript.json` | 매니페스트 (웹앱: 배포자 권한으로 실행, 누구나 접근) |

## 설치 방법

1. 성적 스프레드시트를 열고 **확장 프로그램 → Apps Script**를 엽니다.
   (스프레드시트에 바인딩하면 시트 상단에 `성적 확인 웹앱` 메뉴가 생깁니다.)
2. 편집기에 파일 4개를 만들고 내용을 붙여 넣습니다.
   - `Code.gs`
   - HTML 파일 `Index`, `Stylesheet`, `JavaScript` (`+` → HTML, 확장자 `.html`은 자동으로 붙음)
3. (선택) **프로젝트 설정 → "appsscript.json" 매니페스트 파일을 편집기에 표시**를 켜고 `appsscript.json` 내용을 붙여 넣습니다.
4. `Code.gs` 맨 위 `CONFIG`의 시트 ID, 시트 이름, 폴더 ID를 확인합니다. 지금 시트에 맞게 이미 채워 두었습니다.
5. 편집기에서 `testFirstStudentReport`를 한 번 실행해 권한을 승인하고, 실행 로그로 결과를 확인합니다.
6. 시트 메뉴 **성적 확인 웹앱 → 학생-PDF 매칭 점검**으로 PDF가 빠진 학생이 없는지 확인합니다.
7. 시트 메뉴 **성적 확인 웹앱 → PDF 링크 공유 켜기**를 실행합니다. (아래 "PDF 공유" 참고)
8. **배포 → 새 배포 → 유형: 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** (학교 계정으로만 열게 하려면 해당 도메인을 고릅니다.)
9. 나온 웹앱 URL을 학생들에게 안내합니다.

코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 학생 화면에 반영됩니다.

## 시트 형식

시트를 자동으로 읽기 때문에 문항 수나 열 위치가 바뀌어도 동작합니다.

- 머리글 행: `총합`(또는 `총점`)이 있는 행. `학년`, `반`, `번호`, `성 명`(또는 `이름`) 열이 있어야 합니다.
- 문항 열: `성 명` 열과 `총합` 열 사이의 열
- 배점 행: 머리글 위쪽에서 `배점`이라고 적힌 행 (표 머리글에 `/8`처럼 표시)
- 학번: 학년 1자리 + 반 2자리 + 번호 2자리 (2학년 8반 8번 → `20808`)
- 표준편차: 시트의 `STDEV`와 같은 표본 표준편차

## PDF 파일

- 파일 이름: `학번_이름.pdf` (예: `20808_여송주.pdf`)
- 맥에서 올린 파일처럼 한글 자모가 분리된 이름(NFD)이나 공백이 섞인 이름도 찾습니다. 이름이 달라도 학번으로 시작하는 파일이 하나뿐이면 그 파일을 씁니다.
- 폴더 목록은 10분간 캐시합니다. 파일을 새로 올렸다면 메뉴의 **PDF 목록 캐시 비우기**를 실행하세요.

### PDF 공유

iframe 안의 드라이브 미리보기는 **학생의 브라우저가 직접** 불러옵니다. 그래서 PDF가 비공개면 학생 화면에 "액세스 권한 필요"가 뜹니다.
**PDF 링크 공유 켜기**는 폴더 안 PDF를 *링크가 있는 모든 사용자: 뷰어*로 바꿉니다.
파일 ID(링크)는 로그인에 성공한 본인에게만 전달되므로 다른 학생이 링크를 알아낼 방법은 없습니다. 다만 학생이 자기 링크를 다른 사람에게 넘기면 그 사람도 볼 수 있습니다.

## 보안 옵션

- 학번과 이름만으로는 친구의 성적을 열어 볼 수 있습니다. 개인별 비밀번호를 쓰려면:
  1. 성적 스프레드시트에 시트를 하나 추가합니다 (예: `비밀번호`). A열 `학번`, B열 `비밀번호`, 1행은 머리글.
  2. `CONFIG.PASSWORD_SHEET_NAME`에 그 시트 이름을 적습니다.
  3. 다시 배포합니다. 로그인 화면에 비밀번호 칸이 나타납니다.
- 같은 학번으로 5번 연속 실패하면 10분간 잠깁니다 (`MAX_FAILS`, `LOCK_SECONDS`).

## 설정 바꾸기 (`CONFIG`)

| 항목 | 설명 | 기본값 |
| --- | --- | --- |
| `EXAM_TITLE` | 화면 제목 (비우면 스프레드시트 이름) | `''` |
| `BIN_SIZE` | 히스토그램 구간 크기 | `10` |
| `GRADE_GUIDE` | 등급 안내 기준 | A 67 / B 34 / C 0 |
| `PASSWORD_SHEET_NAME` | 비밀번호 시트 이름 | `''` (사용 안 함) |
